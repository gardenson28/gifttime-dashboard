# 감동타임 선물 트렌드 대시보드

시즌·이벤트 기반 기업 선물 트렌드 리서치 + 임직원 선호도 분석 + 매칭 추천을 하나로 묶은 포트폴리오 대시보드입니다. 가상 기업 선물 서비스 "감동타임" 운영팀의 업무(시즌별 선물 기획, 고객사 맞춤 추천, 임직원 선호도 분석)를 웹 서비스 형태로 구현했습니다.

## 핵심 기능

1. **트렌드 리서치** (`/research`) — 시즌/이벤트 + 예산대를 선택하면 사전 조사된 시즌별 기업 선물 트렌드 데이터(`src/data/trend-research.json`)를 보여줍니다. 이 데이터는 실제 웹 검색 결과를 바탕으로 정리했으며, 각 아이템에 실제 출처 링크가 달려 있습니다. 사전 조사 데이터가 없는 시즌(직접 입력)은 가짜 데이터를 만들지 않고 오류로 안내합니다. (네이버 검색 API 키를 등록하면 그 시즌만 실시간 검색으로 보완할 수 있도록 확장 지점도 남겨뒀습니다 — 아래 참고)
2. **설문 분석** (`/survey`) — 더미 임직원 설문 데이터(60명, `public/sample-survey.csv`) 또는 직접 업로드한 CSV를 분석해 카테고리 선호도, 연령대/부서별 차이, 자유서술 키워드·감정을 시각화합니다.
3. **매칭 추천** (`/recommend`) — 위 두 결과를 규칙 기반으로 조합해 추천 선물군 TOP3와 근거를 자동 생성하고, CSV로 내보낼 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속.

## 트렌드 데이터 갱신/확장

- `src/data/trend-research.json`에 시즌별 아이템(이름/카테고리/가격대/이유/출처)이 정리되어 있습니다. 새 시즌을 추가하거나 항목을 갱신하려면 이 파일을 편집하면 됩니다. (모든 항목은 실제 검색 결과를 바탕으로 작성되었으며 출처 링크가 함께 있습니다.)
- 사전 조사 데이터에 없는 시즌(예: "직접 입력"으로 새로운 이벤트명 입력)을 실시간으로 검색하고 싶다면, 네이버 검색 API를 연동할 수 있습니다:
  1. https://developers.naver.com/apps/#/register 에서 애플리케이션 등록
  2. 발급받은 Client ID / Client Secret을 `.env.local`에 입력:
     ```
     NAVER_CLIENT_ID=발급받은값
     NAVER_CLIENT_SECRET=발급받은값
     ```
  3. 개발 서버 재시작 — 사전 조사 데이터셋에 없는 시즌만 자동으로 네이버 쇼핑 검색으로 보완됩니다.

키를 설정하지 않아도 사전 정의된 8개 시즌(설날/추석/입학/졸업/여름휴가/연말/입사/승진)과 설문 분석·매칭 추천 기능은 모두 정상 동작합니다.

## 데모 시나리오

1. 홈에서 "추석" + "3만~5만원" 선택
2. 트렌드 리서치 실행 → 사전 조사된 추석 선물 트렌드 확인
3. 설문 분석에서 더미 데이터 불러오기 → 분석 실행
4. 매칭 추천에서 TOP3 추천 선물군과 근거 확인 → CSV 내보내기

## 기술 스택

Next.js(App Router, TypeScript) · Tailwind CSS · Recharts · PapaParse · Next.js Route Handler

## 데이터 및 개인정보
